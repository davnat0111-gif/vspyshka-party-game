# Вспышка — игра на реакцию для компании

Браузерная игра для 2–4 игроков на одном экране. Телефон кладут на стол, и каждый жмёт на свой угол. На компьютере или ТВ у каждого своя клавиша (A, L, Z, M).

**Играть:** https://davnat0111-gif.github.io/vspyshka-party-game/

## Как играть
10 раундов, каждый раунд — новое правило:
- **Вспышка:** жми, когда загорится звезда
- **Не верь словам:** жми, когда слово написано зелёным цветом, а не когда написано «зелёный»
- **Только круг:** квадрат и треугольник — ловушки
- **Ровно пять:** числа растут, жми точно на 5
- **Пара:** жми, когда два значка совпадут

Первый, кто нажал правильно, получает очко. Нажал раньше времени — минус очко и пропуск раунда. В конце пьедестал и конфетти.

## Как сделано
- Чистые HTML, CSS и JavaScript, один файл, без библиотек
- Мультитач: каждый угол экрана — отдельный игрок; на телефоне подписи верхних игроков развёрнуты к ним
- Звуки генерируются через Web Audio API, конфетти на Canvas
- Раунды — отдельные «режимы» с общим движком: легко добавить новый
- Автотест прогоняет партию из 10 раундов на 4 игроков
